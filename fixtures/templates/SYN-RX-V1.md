# SYN-RX-V1 synthetic template

UTF-8 text. First line is SYN-RX-V1. Each entry has these ordered lines: medicineName, strength, form, instructionText, startDate, endDate, prescriberName. Use `key: value`; separate entries with `---`. Strength is a number followed by an uppercase unit. Nullable fields use literal `null`. Instruction whitespace is significant. See documents/ for synthetic examples.
